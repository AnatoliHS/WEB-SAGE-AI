(Concepts) Loader

Four line loaders that become the page.

Each one is just a thin line and the four words, Idea, Build, Remix and Share, in Anton, the same face as the wordmark. Every loader ends the same way: the line stretches to the margins and glides into place as the hero's divider, and TINKER CLICK rises above it. The loader never really leaves; it turns into the layout.

Each one plays when you scroll to it, and Replay runs it again.

Rule

B

Timeline

The line draws once from margin to margin, like a ruler. Each time it reaches a quarter, a small tick rises and the next word sits on top of it, so the four steps read left to right. When the line reaches the end, the labels lift away and the full-width line simply moves up into place.

  • Full width

C

Rise

The line draws in at the exact height of the hero's divider and never moves. Each word rises out from behind it, holds for a beat and sinks back down. After Share, TINKER CLICK rises from the same line in the same way, so the loader and the hero are one continuous motion.

  • Line stays put
  • Rise + sink

Underline

One word at a time in the centre, with an underline that resizes to fit each word, like a tab indicator, and takes on that step's colour. It's the only one with colour, and only on the line. After Share, the word lifts away, the underline returns to ink, and it stretches out into the divider.

Recommendation: C, Rise. It's the simplest, with one line that never moves, and it uses the same motion as the wordmark, so there's no visible hand-over at all: the loader is the hero's opening. B is the pick if you want the four words to read as a sequence.

Whichever we pick, when it goes live:
  • Play it once per session (sessionStorage), not on every return to the page.
  • Skip it entirely for visitors who have turned on reduced motion.
  • Draw it over the hero that's already rendered, so search engines and screen readers still get the page straight away.
  • The line must land on the real hero rule, so measure the rule's position at runtime rather than hard-coding it.
